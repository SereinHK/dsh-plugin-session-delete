The two irreversible actions in the trash are red.

- **"Empty the trash"** and a row's **"Delete for good"** take the theme's destructive
  colour: outlined while they are just an offer, filled once the confirmation is showing.
- `Button` has no danger variant (only `primary`, `ghost`, `outline`, `toolbar`), so the red
  is read from the token the menu row's `danger` uses — `--dsw-alias-state-error-primary` —
  rather than written as a literal, so it still follows the theme in light and dark.
- Pinned by three checks in the render suite. Writing them exposed a defect in the test
  harness rather than in the code: its `Button` stub dropped `style`, so a colour assertion
  could never have failed.

**Verified:** 31 package tests, 95 host-route checks against the built bytes, 67 render and
interaction checks.
