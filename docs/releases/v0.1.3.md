The cleanup shows what it removes, and the plugin checks its own assumptions.

**Added**

- The durable-facts route reports each Session's **title** — read from the same
  projection cache the Session list itself uses — and the **bytes** it occupies. The
  dialog names conversations the way an operator recognises them and says what the run
  reclaims, instead of listing bare workspace paths.
- `tools/verify-runtime-contract.mjs`: the plugin reads a layout it does not own (the
  JSONL backend's directory naming, the Host's projection record). Run it after a DSH
  upgrade — it decodes real logs and real records and reports, per assumption, whether
  it still holds. On the machine this was written on: 8/8, including `projectKey`
  reproducing the backend's own project directories across 16 real Sessions.

**Changed**

- The delete path resolves both the session root and its target, and refuses a target
  whose real path falls outside the root: string containment cannot see through a link.
  Tested with a real junction pointing outside the root — the removal is refused and the
  files stay.

**Verified:** 28 package tests, 66 host-route checks against the built bytes (a linked
directory refused, title and size reporting, the proven/unproven cases), 48 render and
interaction checks, and the runtime contract check above.

**Install**

```sh
dsh plugin --profile <profile> add https://github.com/SereinHK/dsh-plugin-session-delete.git
```
