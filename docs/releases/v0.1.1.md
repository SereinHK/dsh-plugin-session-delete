Fixes the blank-Session cleanup, which never found anything to remove.

**What was wrong.** The cleanup trusted the `blank` flag on a Session-list row. That flag
describes a Session resident in the current process — for a Session loaded from disk it
carries no information — so every stored Session looked non-blank and a run always
reported "nothing to clean".

**Fixed**

- Blankness now comes from the durable projection (`sessionListMetadata`, derived from the
  stored events) instead of the live list flag.
- A row whose metadata has not arrived is treated as unproven rather than assumed:
  nothing irreversible happens on a guess.
- The activity timestamp is floored by the durable `lastPromptAt`, so a row cannot look
  idler than it is.
- The dialog's copy no longer claims empty conversations are hidden from the sidebar —
  they are listed, they simply hold nothing.
- New cases cover the durable flag, the unproven row, and the `lastPromptAt` floor.

**Verified:** 24 package tests, 39 host-route checks against the built bytes, 43 render and
interaction checks.

> makes a removal restorable.
